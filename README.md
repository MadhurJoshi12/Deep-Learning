## 🧠 Core Concepts

Throughout this journey, I focused on understanding the mathematics and mechanics behind neural networks.

A basic neural network can be represented as:

$$
z = Wx + b
$$

followed by an activation function:

$$
a = f(z)
$$

The model learns its parameters by minimizing a loss function through optimization and backpropagation.
